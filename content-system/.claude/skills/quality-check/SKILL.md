# Quality Check

Последний шаг контент-системы. Проверяет то, что написали `write-post`
или `reels-script`, до публикации.

## Чек-лист

### 1. Хук
- [ ] Первая строка работает без остального текста
- [ ] Нет захода «В современном мире», «Все мы знаем», «А вы задумывались»
- [ ] Видно, о чём текст, за 2 секунды

### 2. Структура
- [ ] Одна мысль — один абзац
- [ ] Абзацы не длиннее 4 строк
- [ ] Есть вывод, а не обрыв на середине

### 3. Содержание
- [ ] Есть минимум один конкретный пример, цифра или кейс
- [ ] Читатель уносит применимое действие, а не общее ощущение
- [ ] Нет утверждений, которые нельзя подтвердить

### 4. CTA
- [ ] Ровно одно целевое действие
- [ ] Сформулировано глаголом и предельно просто
- [ ] Соответствует этапу прогрева из контент-плана

### 5. Язык
- [ ] Нет канцелярита: «является», «осуществлять», «данный», «в рамках»
- [ ] Нет пустых усилителей: «очень», «действительно», «поистине»
- [ ] Абзацы не начинаются подряд одинаково
- [ ] Тон совпадает с тем, как эксперт говорит вслух

### 6. Признаки ИИ-текста
- [ ] Нет перечислений строго по три в каждом предложении
- [ ] Нет конструкций «не просто X, а Y» подряд
- [ ] Нет тире вместо запятых через строку
- [ ] Нет финального абзаца-морали «В конечном счёте, всё сводится к...»

### 7. Формальное
- [ ] Объём под площадку (Instagram 900–2000, Telegram 600–1500 знаков)
- [ ] Опечатки, согласование падежей, единый стиль кавычек
- [ ] Обещание из хука закрыто в тексте

## Выход

1. **Вердикт** — публиковать / доработать / переписать
2. **Что сломано** — список конкретных мест с цитатой и почему это не работает
3. **Исправленная версия** — целиком, готовая к публикации

Не ограничивайся замечаниями: всегда отдавай переписанный вариант.
